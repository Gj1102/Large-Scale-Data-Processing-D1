# 实验截图清单与可验证素材

所有记录均来自既有实验；下列文件是原始文本或数据，不是实验过程的桌面截图。截图应显示真实窗口、命令和结果，保留能佐证真实性的非敏感主机名或用户名，不暴露密码、令牌。

| 待截图内容 | 对应已有素材 | 证明范围和限制 |
| --- | --- | --- |
| 环境、CPU、内存、PyTorch | `results/environment.json` | 已记录环境信息；物理核心、网络和存储类型仍需补充 |
| 双进程 Gloo 启动 | `code/src/launch.py`、`results/repeated/A2_r1_config.json`、`results/repeated/A2_r1.log` | 配置和已有日志可核对；日志本身不显示两个进程 ID，应实际展示运行中的两个进程 |
| A1/A2 训练 | `results/repeated/A1_r1.log`、`results/repeated/A2_r1.log` | 记录更新耗时和 loss；两组采样顺序未逐样本对齐 |
| B1/B2 训练 | `results/repeated/C4_normal_r1.log`、`results/repeated/C4_delayed_r1.log` | 已运行的每次更新输出及对照配置 |
| 自动正确性验证 | `results/repeated/verification.log` | 两策略梯度、更新参数、rank 与单进程参考误差 |
| Profiler | `results/profile_repeated/K4_normal_communication.json`、`K4_delayed_communication.json` | rank 0 合成输入的独立 profiler 事件，不代表实际 CIFAR-10 基准的额外通信开销 |
| 实验图 | `figures/repeated/` | 基于真实 CSV 的统计图，不证明实验进程实际启动 |
| 测试集评估 | `results/evaluation_evaluation.json` | 训练两步后的准确率只用于验证评估流程 |

将真实截图插入报告“实验步骤”，标注来源、日期和截图所示的具体运行；报告中的统计图与过程截图应明确区分。不能声称重现展示截图就是对历史性能结果的实时记录。
